Specification 23: Sports League &amp; Match Scheduling
Problem Statement: Design and implement a Java console application for a Sports League system
that manages teams, players, fixtures, results, standings, and disciplinary records. The application
should demonstrate object-oriented principles and ensure consistent scheduling and rankings.
Class Requirements: Team, Player, Fixture, Match, Result, Standing, DisciplinaryRecord
Business Rules:
1. Fixtures must be scheduled without team clashes at the same time.
2. Match results update team standings immediately.
3. Points and goal/run differences affect rankings.
4. Disciplinary actions (cards/penalties) must be recorded and reflected.
5. Player participation must belong to the registered team.
Menu Options: Add Team / Add Player / Create Fixture / Record Match / Update Result / View
Standings / View Disciplinary Log / Exit
Expected Output:
• Show fixture list and updated results.
• Show live standings with points and tie-breakers.
• Show disciplinary logs per team/player.
